Política de privacidade

Produtora métricas · em vigor desde 26 de outubro de 2026

O que a ferramenta acessa

Somente as métricas dos canais do YouTube do próprio dono, pelas APIs YouTube Analytics e YouTube Reporting, com o escopo de somente leitura yt-analytics.readonly. Ela não publica, não altera e não apaga nada no YouTube, e não acessa e-mail, contatos, arquivos nem dados de outras pessoas.

Onde os dados ficam

As métricas e a autorização ficam guardadas no computador do dono. Não são vendidas, compartilhadas nem enviadas a terceiros. Os números podem ser lidos por um assistente de IA que o próprio dono usa, apenas para escrever os seus relatórios de desempenho.

Uso limitado

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions, e os dados locais podem ser apagados pelo dono no próprio computador.

English summary

This personal tool reads only the owner's own YouTube channel analytics with the read-only yt-analytics.readonly scope. Data stays on the owner's computer, is never sold or shared with third parties, and may be read by an AI assistant the owner uses solely to write the owner's own reports. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
